# House Binder

Property management and maintenance documentation for our home.

This repository serves as a central source of truth for:

- Lawn care
- Irrigation
- Landscaping projects
- Home maintenance
- Equipment records
- Seasonal schedules
- Application logs

## Goals

- Document what works and what does not.
- Track changes over time.
- Maintain repeatable maintenance procedures.
- Store product recipes and application schedules.
- Provide future reference for projects and repairs.
