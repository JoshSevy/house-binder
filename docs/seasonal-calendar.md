# Seasonal Calendar

## January

- Review irrigation system plans
- Order seed and supplies
- Review previous year's notes

## February

- Schedule spring projects
- Inventory fertilizer supplies

## March

- Inspect sprinkler heads
- Plan aeration if needed

## April

- Spring fertilizer applications begin
- Overseeding as needed
- Activate irrigation system

## May

- Monitor new seed
- Adjust watering schedules
- Spot treat weeds

## June

- Transition to summer fertilizer blend
- Monitor heat stress
- Catch-can testing

## July

- Focus on water management
- Reduce nitrogen inputs

## August

- Plan fall overseeding
- Evaluate thin areas

## September

- Primary overseeding season
- Fall fertilizer program
- Aeration if needed

## October

- Winterize irrigation
- Final fertilizer applications

## November

- Document lessons learned

## December

- Update binder
- Plan next year's projects
