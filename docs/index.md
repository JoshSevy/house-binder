# House Binder

A digital home binder for maintenance records, seasonal routines, projects, vendors, equipment, and lessons learned.

## Start Here

- [Seasonal Calendar](seasonal-calendar.md): Month-by-month reminders for recurring work.
- [Project Backlog](projects/backlog.md): Open improvements and future ideas.
- [Completed Projects](projects/completed-projects.md): Finished work and historical decisions.
- [Equipment](house/equipment.md): Models, settings, manuals, and warranty details.
- [Product Log](house/product-log.md): Materials, supplies, and application notes.
- [Vendors](house/vendors.md): Contractor and service-provider reference.

## Core Areas

### Lawn

Use this section for fertility, seeding, watering, weed control, insect control, and problem-area notes.

### Irrigation

Use this section for Rachio setup, zone mapping, catch-can tests, and controller notes.

### Landscaping

Use this section for shrubs, retaining walls, drainage, and other exterior projects.

### Logs

Use this section as the running history of what happened, when it happened, and what changed afterward.

## Product Direction

The website is the first version of the binder. Keeping the content structured here will make it easier to reuse the same sections, records, and workflows later in native iOS and Android apps.
