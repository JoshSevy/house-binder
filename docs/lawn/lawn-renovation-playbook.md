# Lawn Renovation Playbook

## Phase 1 - Assessment
- Photograph lawn
- Map thin areas
- Identify weeds

## Phase 2 - Weed Control
- SpeedZone
- Wait reseeding interval

## Phase 3 - Renovation
- Core aerate
- Overseed
- Topdress
- Apply mesotrione

## Phase 4 - Establishment
- Keep seed moist
- Resume soil program
- First mowing

## Phase 5 - Spring Follow-up
- Apply Prodiamine
- Spot seed if needed
