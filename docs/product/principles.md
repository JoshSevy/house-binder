# Product Principles

The markdown binder is not throwaway work.

It is the first version of the product, the first data model, and the first real-world test case.

1. Data First

Every feature begins with the data model.

---

2. Offline First

The application should work without internet.

---

3. User Owns Their Data

Users can export everything.

---

4. Recommendations Over Ads

Only recommend products that genuinely solve problems.

---

5. Long-Term Thinking

Every feature should still make sense five years from now.
