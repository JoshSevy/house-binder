# ADR-0001: Markdown First

## Decision

Start with Markdown files as the first data model and source of truth.

## Why

- Easy to edit
- Easy to version
- Easy to export
- Human-readable
- Works before the app exists
- Keeps the product grounded in real homeowner needs

## Future Direction

Eventually, property data may move into a database while Markdown remains supported for import/export, templates, and documentation.
