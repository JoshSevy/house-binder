# Product Vision

## Goal

Build a home/property operations platform that helps homeowners plan, document, and maintain recurring home and yard tasks.

## Core Features

- Property dashboard
- Seasonal task calendar
- Product and recipe tracking
- Application logs
- Irrigation zone data
- Photo history
- Project backlog
- Email/text/push reminders

## Future Integrations

- Weather API
- Rachio API
- Calendar reminders
- Soil temperature tracking
- GitHub export/import
