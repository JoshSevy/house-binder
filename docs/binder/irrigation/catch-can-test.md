# Catch Can Testing

## Purpose

Determine:

- Precipitation rate
- Coverage uniformity
- Dry spots
- Overwatered areas

---

## Procedure

1. Place 6-10 cups throughout zone.
2. Run zone for 15 minutes.
3. Measure water depth.
4. Average results.
